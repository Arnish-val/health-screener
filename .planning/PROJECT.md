# Project: Health & Wellness Screener

## Vision
A high-fidelity, portfolio-ready healthcare assessment platform that demonstrates engineering excellence to recruiters. It features clean architecture, automated testing, and premium UI/UX with AI-driven insights.

## Goals
- **Engineering Excellence**: Implement a service layer, reusable component library, and proper API structure.
- **Recruiter Appeal**: Professional dashboard, authentication, real-time charts, and smooth scrolling animations.
- **AI Integration**: Enhance the screening process with intelligent feedback and risk analysis.
- **User Trust**: Prominent medical disclaimers and accessible design.

## Core Stack
- **Frontend**: React (Vite), Tailwind CSS v4, Framer Motion (Animations), Lucide (Icons), Chart.js (Visualizations).
- **Backend**: FastAPI (Python), Pydantic (Validation), JWT (Authentication).
- **ML/AI**: Scikit-learn, XGBoost (Current), potential LLM integration for result explanation.
- **Testing**: Pytest (Backend), Vitest + React Testing Library (Frontend).
- **Deployment**: Render (Unified Web + Static Service).

## Design System
- **Theme**: Dark Mode (OLED) - Medical & Trustworthy.
- **Colors**: Slate-900 (Primary), Slate-800 (Secondary), Emerald-500 (CTA/Accent), Slate-950 (Background).
- **Typography**: Figtree (Headings), Noto Sans (Body).
