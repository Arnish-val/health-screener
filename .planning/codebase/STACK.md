# Stack Map

## Frontend
- **Framework**: [React](https://react.dev/) (v19)
- **Build Tool**: [Vite](https://vitejs.dev/) (v8)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/) (v4)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **HTTP Client**: [Axios](https://axios-http.com/)

## Backend
- **Framework**: [FastAPI](https://fastapi.tiangolo.com/)
- **Server**: [Uvicorn](https://www.uvicorn.org/)
- **Validation**: [Pydantic](https://docs.pydantic.dev/)
- **ML Runtime**: [Scikit-learn](https://scikit-learn.org/), [Joblib](https://joblib.readthedocs.io/), [NumPy](https://numpy.org/), [Pandas](https://pandas.pydata.org/)
- **ML Models**: [XGBoost](https://xgboost.readthedocs.io/)

## ML Pipeline
- **Language**: Python
- **Tools**: Scikit-learn, XGBoost, Pandas, NumPy
- **Storage**: Joblib for pipeline serialization

## Deployment
- **Platform**: Render (via `render.yaml`)
